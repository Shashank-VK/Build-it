# Mobile Release Discipline

- Five structural differences from web: store review, staged rollout, crash budgets, forced-update path, offline behavior.
- Release train: beta cohort → 10% → 100% with crash-rate gates between stages.
- Rollback = expedited store submission + remote kill-switch; both rehearsed.
