# FinOps Discipline

- Attribute cloud cost per feature (tag: project/feature). Review weekly.
- Budgets: daily model-spend cap via scripts/spend-log.sh ($10 default, 80% warn).
- Cost/latency/reliability budgets for every AI feature (see eval-gate workflow).
- Kill-switch: spend alerts page before overrun, not after.

Ref: `../how-to-use/00-rules.md` (finops cards).
