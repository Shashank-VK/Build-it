# 09 — Scrapbook / Collage-Multilayer

> Style researcher 9/10. Read-only, no installs. Search-verified 2026-10-09.

## 1. Documented meaning
- Physical scrapbook/moodboard logic on screen: torn paper, tape, stickers, overlapping photos, handwriting + type collisions, visible craft.
- Documented in: Designmodo "Crafty Multilayerness — Scrapbook Style in Web Design" (multilayer via collage; warns messy-if-unplanned) — https://designmodo.com/scrapbook-website-design — 🔍 Search-verified; Adobe Express digital-scrapbook how-to (format/template/AI-template-generator flow) — 🔍 Search-verified; Detroit encyclopedia Dada/absurdist-collage lineage (cousin).
- Digital meaning: intimacy/nostalgia/authenticity; zines, weddings, creator brands, fan culture.

## 2. Characteristic visual elements
- Torn/ripped edges, washi tape strips, paper clips, polaroids with captions, sticker bursts.
- Overlapping rotated cards, mixed paper stocks (kraft, grid, lined), doodle underlines/arrows.
- Handwritten + serif + mono type collisions; stamp/label ephemera.
- Grain/photocopy noise, drop-tape shadows (small, soft, layered — not neumorphic).
- Dense-but-anchored composition: one tape-grid or spine holding chaos together.

## 3. Digital applications
- Wedding/baby/memory books, creator link-in-bio collages, zine sites, moodboard portfolios, IG-story-style web stories, classroom/club pages.
