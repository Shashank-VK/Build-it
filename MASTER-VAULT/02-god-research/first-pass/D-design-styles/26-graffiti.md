# 26 — Graffiti

## Meaning
Graffiti / graffiti art / street-art-lettering = word-based (vs image-centred street art) public writing turned design language. Modern form originates 1970s New York (spray on buildings / subway trains), one of hip-hop's four elements, later absorbed into galleries via Basquiat, Haring, Banksy, Barry McGee. As graphic design: digital recreation of tags, murals, textures to capture rebellious energy; analytics via line / color / structure + artist intention same as fine art.

## Elements
- Forms: tag (monochrome signature / monogram), throw-up (fast 2-color bubble/outline), block / blockbuster (large blocky 3D rectangles for coverage), bubble / popcorn letters, wildstyle (intricate interlocking calligraphy + arrows/spikes, often illegible), semi-wildstyle, 3D / photorealistic 3D (vanishing-point, multi-day), stencil (cardboard/paper cutouts), heaven spots (hard-to-reach placements), sticker art, abstract / brush / fat-cap styles
- Graphic treatments: bold hand-drawn typography, outlines, detailed fills, 3D depth / shadows / highlights, drips / overspray / spatter / marker streaks, distressing, spray textures, raw messy composition; bubble, wildstyle, stencil, drip fonts in digital use
- Color / composition: saturated palettes, strong contrasts, free compositions defying rules; energy / movement on flat surface via scale + style
- Distinction preserved: graffiti = normally word-based; street art = image-centred; graffiti art = amalgamation (Adobe source)

## Uses
- Streetwear, album covers, posters, social content, branding for edgy / youthful audiences, flyers, logos (selectively), editorial / campaign protest messaging (stencil legibility), murals, fashion customization (garments as walls), digital art / NFTs / motion / mapping
