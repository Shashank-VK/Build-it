# 25 — Synthwave

## Meaning
Synthwave / Retrowave / OutRun / Futuresynth = earnest, celebratory retro-futurism that modernizes 1980s–90s visual + musical language. As music microgenre (2000s revival of 80s synthpop / film soundtracks: Carpenter, Jarre, Vangelis, Tangerine Dream) + as internet visual aesthetic (early 2010s crystallization around album covers, games, VHS art). Term OutRun from 1986 arcade `Out Run`. Unlike Vaporwave's ironic detachment, Synthwave is sincere nostalgia amplified to mythic proportions — "the 80s future that never arrived."

## Elements
- Palette: dark foundation (midnight navy #0D0221, deep purple, black) + sunset gradient (magenta hot pink #FF1493/#FF2A6D, orange #FF6B35, purple) + cool accents (electric cyan #00E5FF/#05D9E8, neon blue) + chrome silver #C0C0C0; glow replaces shadow (colored halos, bloom, flicker)
- Signature motifs: oversized striped setting sun, perspective laser grid floor to vanishing point, palm-tree / sports-car (DeLorean/Lamborghini/Ferrari) / cityscape silhouettes, chrome typography, neon monoline borders, VHS tracking lines / scanlines, starfields, chevrons / triangles / diamond grids, retro tech (cassettes, arcade cabinets, aviators)
- Typography: bold chrome sans-serif + handwritten neon script; uppercase heavy tracked hot pink as brightest element; Orbitron-type futuristic faces
- Motion / light: pulse / flicker / bloom like neon gas; diagonal speed lines, motion blur; smooth cinematic gradients
- Music correlate: 80–118 BPM (upbeat 128–140), instrumental synth, subgenres dreamwave / darksynth / scifiwave

## Uses
- Album covers, streaming visualizers, electronic-music events, gaming (Hotline Miami, Far Cry: Blood Dragon), YouTube / streaming branding, tech startup / event marketing, portfolio / agency sites, neon poster / merch design

## Overlap note — preserve terminology
- vs Cyberpunk: both 80s neon but opposite meanings per vocab.design + StyleShift: Synthwave = hopeful sunset optimism; Cyberpunk = noir dystopia.
- vs Vaporwave / Retrowave / OutRun / Futuresynth: sources list these as aliases or adjacent umbrella terms; author Nicholas Diak cited: retrowave as umbrella encompassing synthwave + vaporwave. Do not collapse ironic Vaporwave (pastel surreal) into earnest Synthwave.
- vs Cybercore-A: Cybercore remixes late-90s/2000s web + anime melancholy; Synthwave stages 80s highway-sunset power. Keep separate.
