# 14 — Conceptual Sketch (Hand-drawn / Sketchy UI)

> Research date: 2026-10-09 | Researcher: Styles 11-20 | Methods: WebSearch + WebFetch

## Meaning
Style whose lines wobble as if sketched by hand, signaling **provisional, not finished**. Also called sketchy UI, rough style, wireframe aesthetic, lo-fi look, Excalidraw style. Job is communication (this is a draft — argue with it), not decoration. Rooted in early-stage ideation; Jonson (2005) shows freehand sketch as traditional conceptual tool, though verbalisation often starts ideation.

## Key Elements
- Bowed straight lines, doubled / retraced strokes, overshooting corners that cross rather than meet
- Hachure fills (diagonal pen strokes) instead of floods; 0.1–0.25 pen detail / 0.5 regular / marker thick / one color accent
- Hand-lettered or sketch-look type (e.g. handwriting faces), 1–2° off-square, ALL CAPS if handwriting weak, horizontal annotations only
- Basic-shape vocabulary: lines / squares / circles / ovals / triangles = UI patterns; sticky-note overlays for variants
- Tooling: Rough.js (jittered paths), Wired Elements (sketchy form controls), Excalidraw (deterministic wobble per shape, no repaint reshuffle)
- Keep strokes measurable for contrast; lettering large; avoid sketch dress on trust/money flows

## Applications
- Whiteboard tools, architecture diagrams, early product concepts, docs that want critique, teaching material
- UI sketching → wireframing handoff, Justinmind Sketching UI kits, workshop facilitation
- Portfolios of illustrators (signals creativity) — but fits badly where trust/payment required

## Gap
Nuance gap: abundant **process** guidance, scarce **production** system treating sketch as final brand. Using sketch chrome on shipped apps breaks its promise (provisional → decorative). No WCAG-tuned sketch component library verified; treat as draft-phase style unless custom contrast work done.
