# 22 — Anthropomorphic

## Meaning
Anthropomorphic design = attribution of human traits — shape, gesture, character, awareness / speech / emotion — to non-human subjects (animals, plants, objects, machines). From ritual vessels / Egyptian gods / Aesop to Felix the Cat (1919), Disney, Looney Tunes, Sonic, Zootopia. In product / graphic / character design it is a deliberate method to evoke emotional response and readability: familiar, cute, expressive vs boring / purely human options.

## Elements
- Four kinds (CMU / DiSalvo): structural (body-plan mimicry), gestural (pose / movement), aspects of character (personality / role cues), awareness (apparent sentience / gaze / interaction)
- Character craft: silhouette readability, shape language (round = friendly, angular = danger, square = stable), head-unit proportions (e.g. 2-head cute / chibi vs realistic), eyes (dot / humanlike / highlight / line), mouth, limbs, clothing / accessories
- Product variant: curves / angles inspired by human form (e.g. Coca-Cola bottle), faces on front-ends / packaging, vegetable / fruit + faces / limbs in kitchen goods
- Techniques: simplification + exaggeration consistently; study animal anatomy + muscle then adapt to bipedal / expressive form

## Uses
- Animation, games, comics, children's books / film, mascots / brand characters, advertising, toys / merchandise
- Product design (radios, lamps, vehicles, robots e.g. Honda Asimo), UI / learning media (anthropomorphic agents to elicit positive affect), furry / fursona culture, editorial illustration
- Design functions identified: making things familiar, keeping things same, reflecting product attributes, projecting human values; seductive (lead to purchase/use) vs fulfillment
