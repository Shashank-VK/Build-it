# 11 — Claymorphism

> Research date: 2026-10-09 | Researcher: Styles 11-20 | Methods: WebSearch + WebFetch

## Meaning
Claymorphism is a playful UI style that makes elements look like soft, puffy pieces of clay / plasticine. Coined by Michał Malewicz (~2021-2022), it evolved from neumorphism but fixes its accessibility problems: elements **float above** the background instead of being fused to it.
Philosophy: inflated, soft 3D, friendly, toy-like, healing. Highest acceptance for consumer / youth / female-oriented apps.

## Key Elements
- Very large border-radius: 20-32px cards, 16-20px buttons
- Pastel fills + gradients: sky #7DD3FC, lavender #C4B5FD, peach #FCA5A5, mint #6EE7B7, lemon #FDE68A
- Multi-layer shadow recipe: 1x outer drop `0 12px 24px rgba(13,37,72,0.12)` + 1x top light + 2x inset highlights
- Thick / white borders, matte surfaces, chunky icons
- Press feedback: raised normal → inset indented on `:active`
- Typography: rounded heavy display + simple friendly sans; short headings
- Motion: buoyant lift, squash-and-stretch, gentle bounce on success
- Low-medium density, floating clusters, generous whitespace, min tap 44x44px

## Applications
- Education / EdTech, onboarding, creative tools, lifestyle, social, kids apps
- Dashboard cards, profile sections, bottom nav, CTA buttons
- Food / restaurant, creator economy - per Artifx industry mapping
- Dark variant also possible (Dark Claymorphism Card UI example)
