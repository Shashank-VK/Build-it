# 16 — Editorial

> Research date: 2026-10-09 | Researcher: Styles 11-20 | Methods: WebSearch + WebFetch

## Meaning
Magazine / print-craft brought to web: page laid out like a spread, not stacked sections. Type ranks content (what to read 1st/2nd/3rd). Feels literate, considered, calm — you sit down with it. 2026 variant: Archival Index / founder editorial heroes replacing generic slogan+CTA heroes (multiple entry points cut bounce ~21% for returners per Baymard 2026).

## Key Elements
- Type does talking: high-contrast serif display (e.g. Gelasio), italics for voice, real weight for emphasis
- Columns hold page: 6-8 col desktop grid (print uses 5/7/9), measure 60-75 chars / 45-90 chars (target ~66); modular rows for vertical rhythm
- Rules not boxes: 1px hairlines divide; no drop shadows / rounded containers
- Kicker / headline / deck pattern + pull quotes, captions, folio moments; breakout image only when rule is sensed
- Ink/paper + one accent: near-black #111111/#111827 on warm off-white #FFFFFF/#F1F1F1, accent sparingly for links/labels; scale 14/16/18/24/32/40, 8pt baseline
- Motion as temporal grid: sticky elements, parallax, scroll reveals, reading progress; whitespace creates section breaks, not page turns
- A11y: hierarchy must survive without color; tabular numerals for data; check placed PPI + responsive crops

## Applications
- Digital magazines, newsletters, brand journals, case-study libraries, product libraries, founder sites, longform blogs
- Squarespace Revel / Adri templates (Archival Index, Card Play), Stripe Config 2026 tertiary-card pattern (image+eyebrow+headline+link, no description)
