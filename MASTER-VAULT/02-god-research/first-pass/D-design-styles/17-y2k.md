# 17 — Y2K

> Research date: 2026-10-09 | Researcher: Styles 11-20 | Methods: WebSearch + WebFetch

## Meaning
Retrofuturistic language of ~1998-2004 when screens first imitated physical materials. Succeeded Memphis, succeeded by Frutiger Aero. Name from David Eddy's Y2K bug shorthand. Mix of dotcom techno-utopianism + rave/hip-hop + toy packaging. Revived 2020s (nowstalgia, COVID-era resurgence per Yang 2023); broad TikTok use now = 2000s fashion, narrow CARI use = Cybercore/chromecore original.

## Key Elements
- Chrome / liquid metal type, holographic / iridescent gradients, glossy bevel-and-emboss, multichrome oil-spill blends
- Candy brights: electric blue/teal, neon green, hot pink, tangerine + silver/chrome; high contrast for low-res screens
- Bubble forms: inflated rounded sans, pill buttons, blobby backdrops, blobjects (iMac G3, inflatable furniture)
- Cyber-grid: wireframe perspectives, loading bars, rendered buttons, cursor icons as decor, tribal sigils
- Type: chunky / bloated rounded, pixel bitmap, techno/rave, default-font nods (Comic Sans, Times); thick outlines, drop shadows, italics
- Effects: inner glow, neon outlines, glitch/RGB-split/scanlines (short, targeted), grain, fisheye wide-angle, flash photography cutouts with sticker stroke
- Iconography: pixel sets for headings, beveled 3D for CTAs, wireframe+glow for streamlined; one set consistently
- Monochrome variant: gritty B&W for editorial take (Griffo House)

## Applications
- DTC youth brands (Studs, Starface, Billie), music/fashion (Olivia Rodrigo, Off-White, aespa/XG Y3K), portfolios (Ryan Haskins), awards (D&AD Editor X), AR/VR (Gather 8-bit vs metaverse slick)
- Modern sites: DigiValet (pearl hero), Byooooob (candy blocks), Pasha Ink (multichrome), Walrus (bitmap hero + clean body), AKARI (tubelights), Nifty Portal (controlled glitch), Poison Studio (statue cutouts), Unbias (blob behind navy text)
