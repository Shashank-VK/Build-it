# 13 — Pixel Art

> Research date: 2026-10-09 | Researcher: Styles 11-20 | Methods: WebSearch + WebFetch

## Meaning
Deliberate low-resolution, grid-visible graphics rooted in 1980s hardware limits. Term published by Xerox PARC researchers Adele Goldberg and Robert Flegal (1982). Modern use is intentional nostalgia + craft: hand-placed pixels, not just retro. Contemporary wave (Sea of Stars, Eastward, Chained Echoes) favors readable, generous palettes over strict 8-bit.

## Key Elements
- Integer pixel / tile grid; scale only by whole-number factors; disable smoothing / anti-aliasing
- Compact indexed palette: explicit light / midtone / shadow / status colors; avoid accidental intermediate hues; classic 16-color discipline
- Hard stair-stepped edges, tiled borders, pixel corners, block silhouettes; radius 0–0.25rem
- Bitmap icons, sprites, tilemaps, dithered scenes, low-res portraits at consistent native scale
- Typography: blocky bitmap / pixel fonts for headings; clean sans for body to preserve legibility
- Motion: authored frame sequences, stepped movement, palette swaps, sprite cycles — no smooth vector interpolation
- Layout: game-HUD organization (inventories, dialogue boxes, HUD panels); medium density but generous cell size per icon

## Applications
- Games, game menus/settings systems, developer portfolios, entertainment products, retro communities, playful utilities
- Movie app concepts (PixelFlix), plant-shop app, farming RPG menus, Godot 4 Theme (.tres) reskin systems
- Branding for studios / game-adjacent tools where playfulness > corporate trust

## Gap
Partial — strong for games / portfolios; thin for enterprise SaaS / fintech. No canonical accessible pixel design system for data-dense apps. Listed resources cover games well; do not stretch to dashboards without custom legibility work.
