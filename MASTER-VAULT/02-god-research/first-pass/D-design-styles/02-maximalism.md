# 02 — Maximalism

> Style researcher 2/10. Read-only, no installs. Search-verified 2026-10-09.

## 1. Documented meaning
- "More is more": deliberate excess — layered pattern, color, type, imagery — to evoke joy, luxury, rebellion, or subcultural identity.
- Documented in: Adobe Express "What is maximalism in design and branding" explainer; daisyUI Trends "Maximalism UI Design Style" (principles/fonts/moodboard/AI prompt page); Kate Wagner / design-press maximalist-interior lineage applied to web.
- Digital meaning: anti-bland branding, Gen-Z/streetwear energy, editorial collage pages.

## 2. Characteristic visual elements
- Clashing-but-curated palettes; multiple patterns (florals, checker, animal, grain) layered.
- Mixed typefaces (display serif + grotesque + script/mono), oversized headlines, rotated/marquee text.
- Sticker shapes, borders-on-borders, dense collage grids, overlapping cards.
- Heavy texture: grain, foil, velvet gradients, chrome; maximal shadow/stroke use.
- Motion abundance: marquees, parallax stacks, hover chaos (with reduced-motion fallback).

## 3. Digital applications
- Music/fashion drops, festival pages, indie editorial longreads ("Maximalism in web: longread" on Behance), playful SaaS brand pages, portfolio statements.
