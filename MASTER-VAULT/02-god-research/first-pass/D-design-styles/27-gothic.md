# 27 — Gothic

## Meaning
Gothic design = contemporary interpretation of medieval-rooted language (18th-c. architecture revival → literature → Goth subculture UK) centred on finding beauty/fascination in darkness. Modern spectrum: traditional blackletter / cathedral goth to Modern Gothic / futuristic noir (Adobe 2020 trend: cyberpunk + glitch + mysticism + freak-forward) and Pastel Goth (cute + eerie). Communicates mystery, rebellion, prestige, drama, authority.

## Elements
- Typography: blackletter / Old English, high-contrast serif, sharp angular letterforms, vertical emphasis, ornamental flourishes / terminals; often 60pt+ display; pair with neutral sans body to avoid overload
- Motifs: pointed arches, tracery (trefoils/quatrefoils/mouchettes), rose windows (radial symmetry), ribbed/fan vaults, gargoyles/grotesques, crosses/skulls/ravens/thorns/moons, runes/pentagrams/eyes/hands (occult/Wicca/pagan), illuminated borders/seals/emblems
- Color / texture: near-black / dark stone gray / midnight blue grounds, deep desaturated wine purple / oxblood / oxidized green / tarnished gold; single light point in darkness for impact; grain/noise, ink bleed, parchment, letterpress irregularity; stained-glass color work
- Layout: bilateral symmetry, centered compositions, tall narrow containers, layered depth (texture + framework + content + overlay), rough / ragged edges offsetting sharp lines

## Uses
- Metal / horror / fantasy music artwork, scary-film / medieval themes, streetwear + graffiti + punk blends, luxury branding (minimal gothicism for prestige/exclusivity), editorial, festival / game / fashion campaigns, wedding invitations in gothic style, web design dark themes

## Overlap note
- vs Victorian (23): share 19th-c. typography (e.g. Carol Gothic) and ornament, but Victorian = eclectic maximalist commercial print; Gothic = darkness / verticality / occult system. Vs Cyberpunk: Modern Gothic explicitly layers cyberpunk slick surfaces + glitch over grunge; preserve as fusion, not synonym.
