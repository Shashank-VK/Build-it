### SECTION 1 — THE MCP SPECIFICATION AND GOVERNANCE

- **Model Context Protocol (MCP) specification** — *Open protocol specification (JSON-RPC 2.0 based)* — MCP is an open JSON-RPC 2.0 protocol standardizing how LLM agents reach external tools and data. Architecture has three roles: hosts, clients, servers. Servers expose resources, prompts, and tools; clients may offer sampling, roots, and elicitation back. A 1:1 client↔server relationship per client instance; a host may run many clients. — [https://modelcontextprotocol.io](https://modelcontextprotocol.io) — *Verified*
- **Agentic AI Foundation (AAIF) governance** — *Industry foundation / open governance body* — Neutral home for agent standards. Announced 2025-12-09; co-founded by OpenAI, Anthropic, and Block (earlier reports also name OpenAI+Anthropic as the MCP donors). Founding donated projects: Anthropic's MCP, OpenAI's AGENTS.md, Block's goose agent framework. Supporters at launch: Google, Microsoft, AWS, Bloomberg, Cloudflare. Google's A2A protocol joined as … — *Verified*
