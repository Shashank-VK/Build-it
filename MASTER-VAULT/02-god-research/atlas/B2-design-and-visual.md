## UI/UX theory, principles, and audit resources

HCI references, usability heuristics, accessibility/typography/color references, UX audit methods, checklists, and the agent skills that operationalize them. Source: `catalogs/02a-design.md` PART B.

- **B1. Nielsen Norman Group — 10 Usability Heuristics** — *Docs-only (reference article + poster downloads)* — The canonical 10 heuristics: visibility of system status, match with real world, user control, consistency, error prevention, recognition over recall, flexibility, aesthetic/minimalist design, error recovery, help/documentation. — [https://www.nngroup.com/articles/ten-usability-heuristics/](https://www.nngroup.com/articles/ten-usability-heuristics/) — *Verified*
- **B2. UX Project Checklist (uxchecklist.github.io)** — *Implementation-lite (interactive checklist web app, open source)* — Open-source interactive checklist for UX projects: research, plan, explore, communicate, create, feedback, delight, analyse — with per-phase check items and progress tracking. — [https://uxchecklist.github.io/](https://uxchecklist.github.io/) — *Partially verified*
- **B3. Refactoring UI (book + components)** — *Docs-only (commercial book) + implementation-adjacent (Refactoring UI component patterns)* — Tactical UI design book: hierarchy, layout, spacing, typography, color, depth, working with constraints. De-facto styling bible for developers; many AI coding assistants' outputs follow its rules. — [https://www.refactoringui.com/](https://www.refactoringui.com/) — *Verified*
- **B4. W3C WCAG 2.2 + ARIA APG (accessibility references)** — *Docs-only (normative standards + patterns)* — WCAG 2.2 quickref (filterable success criteria, A/AA/AAA); APG provides accessible interaction patterns (dialog, combobox, treeview…) with keyboard/ARIA semantics. POUR principles underpin. — [https://www.w3.org/WAI/WCAG22/quickref/](https://www.w3.org/WAI/WCAG22/quickref/) — *Verified*
- **B5. Baymard Institute (ecommerce UX research)** — *Docs-only (research reports; hosted service/paid)* — Large-scale ecommerce UX research: 130k+ hours of UX research, benchmarked UX guidelines for checkout, product pages, navigation, mobile. Free articles + premium full reports/database. — [https://baymard.com/](https://baymard.com/) — *Verified*
- **B6. Material Motion (motion design guidelines)** — *Docs-only (motion theory + tokens)* — Motion system: easing curves (standard/emphasized), duration tokens (short/medium/long), spatial/temporal patterns, transitions (shared axis, container transform). Reference for motion tokens and micro-interaction timing. — [https://m3.material.io/styles/motion](https://m3.material.io/styles/motion) — *Verified*
- **B7. Typewolf / Fonts In Use (typography references)** — *Inspiration/reference (curated font usage, docs-adjacent)* — Typewolf: what's trending in type, font recommendations, site-of-the-day with type details. Fonts In Use: independent archive of typography in use (print + web), searchable by typeface. — [https://www.typewolf.com/](https://www.typewolf.com/) — *Verified*
