## 1. Minimalism

Secondary coverage (webpronews/webanditnews, 2026-10, citing a March 2026 cssauthor.com ranking) notes these themes stay under ~5 KB gzipped. ## 2. Maximalism

**Documented meaning (digital interfaces):** "More is more" — dense layers, rich textures, overlapping visuals, pattern fills (dots, stripes, checkerboard, halftone), ghost text (12–16 rem at ~0.04 opacity behind content), mixed typefaces (commonly serif display + condensed sans + mono labels in one page), deliberately clashing saturated colors, hard offset shadows, rotated stickers/badges. Sources stress maximalism is *curated excess*, not chaos: one dominant idea per section, density ranked by section, strict grids often holding the chaos (the "maximalist hero that drops to minimalist inner pages" discipline in the award-winning-web-design templates). Positioned explicitly as a reaction against minimal SaaS sameness; ideal for creative agencies, fashion editorials, music festivals, events, lifestyle brands.

## 3. Swiss design / International Typographic Style

**Documented meaning (digital interfaces):** The 1950s Swiss poster tradition mapped to the web via CSS Grid: strict mathematical (usually 12-column) grids; typography as the primary visual element; neutral grotesques (Helvetica/Neue Haas Grotesk, Inter, Roboto) with extreme size contrast (massive headers vs. 1rem body); flush-left/ragged-right text, never centered; asymmetric compositions; very limited color — black/white plus ONE saturated accent (often Swiss red); objective, documentary photography rather than illustration; generous whitespace between grid-locked elements. Sources converge on "the grid is absolute."

Neo-surrealism specifically combines traditional surrealism with modern visual culture using digital tools. On the web this manifests almost entirely through imagery and 3D/CGI illustration (heroes, campaign visuals, editorial art), not through reusable CSS/component systems. ## 6. Neo-brutalism

**Documented meaning (digital interfaces):** The friendly, colorful descendant of web brutalism: thick black borders (2–4px), hard zero-blur offset shadows (e.g. `6px 6px 0 #000`), vibrant flat color fills, sharp or slightly rounded corners, chunky uppercase/headline typography (Space Grotesk, Lexend Mega, Archivo), simple geometric shapes, high contrast. Sources (aavendano/neo-brutalism-css core concepts; ekmas component docs) define it as bold borders + hard shadows + vibrant colors + raw-but-playful aesthetics. Distinct from strict brutalism (#4): color, playfulness, and polish are deliberate. One of the best-resourced styles in this catalog, with libraries across CSS, React/Tailwind/shadcn, Vue, and Blazor.

## 8. Neumorphism

**Documented meaning (digital interfaces):** "Soft UI" / "new skeuomorphism": elements appear extruded from or pressed into a single monochrome background using paired light/dark soft shadows (light source top-left, dark shadow bottom-right) instead of borders or flat fills. Documented characteristics (trixsec/frontend-skills Frontend/UI/Neumorphism/Neumorphism.md): monochrome background matching element color; dual box-shadow defining shape; rounded corners throughout, nothing sharp; low contrast by design — fails WCAG contrast by default and needs deliberate correction. Best for physical-feeling controls (toggles, sliders, dials) and calm single-surface interfaces (music players, thermostats); sources warn against using it as the sole affordance for critical actions.

**Documented meaning (digital interfaces):** Soft modeling-clay UI: puffy, inflated, very rounded (20–50px radius) elements in bright friendly colors that appear squeezable. The signature recipe (from multiple sources, converging): generous border-radius + dual inset shadows (light inset top-left, dark inset bottom-right) to simulate 3D volume + offset outer drop shadow to ground the element. The term was coined by Michał Malewicz (per clay.css README citing hype4.academy). Key distinction from neumorphism: claymorphism floats *above* the background (detached, with drop shadows and contrasting colors), eliminating neumorphism's accessibility and single-surface restrictions. Typography: playful thick rounded fonts (Baloo 2, Sniglet, Fredoka One, Nunito). Motion: bouncy easing, lift-and-squish on press.

## 22. Anthropomorphic design

**Documented meaning (digital interfaces):** Character-led interface design — a brand system built on personality instead of a logo: rounded blob-bodied characters with a shared parametric face, standing on flat ground-line shadows, blinking on independent timers, reacting emotionally to hover. Descends from Clippy (1997) and Japanese kawaii mascot tradition, matured into brand systems like Mailchimp's Freddie and Duolingo's Duo. The core system insight (from the atlas-ori skill): one reusable, parametric `.face` component (eyes/mouth/blush via custom properties) scaled per character — treating the mascot as a static illustration instead of a component is the most common failure. Signature device: the hero mascot's bordered speech bubble with tail — only the hero "talks." Avoid for healthcare, legal, financial, and broad B2B where personality undercuts authority.
