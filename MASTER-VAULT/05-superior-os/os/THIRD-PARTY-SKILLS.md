# Third-Party Skills Registry

Every entry below is an EXTERNAL skill source cited in the research corpus
(B-category-catalogs/09-skills and how-to-use/01-skills.md). Nothing here is
vendored — install on demand with a skill installer (`skill-installer`,
`skref`, `skill-quartermaster`) or `git clone`, then verify with
`task eval-gate` thinking and the fcar-reviewer skill. No install command is
claimed per-repo; check the repo README first.
