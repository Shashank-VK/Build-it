# 34 Engineering Rules (digest)

Full catalogue: `../how-to-use/07-anti-patterns.md` + rule cards. Deve's 10 rules are rules 1-10 below; 11-34 are new.

1. Appetite before solution. 2. Press-release before spec. 3. >=2 Non-Goals. 4. Uphill-first. 5. TDD + evidence exit. 6. FCAR fresh context. 7. No silent skips (waivers visible). 8. Secrets never land. 9. Sandbox untrusted code. 10. Launch checklist before deploy.
11. Contract-first APIs (OpenAPI/Protobuf, date versioning). 12. Migrations reversible + timed on copies. 13. One skill per job; progressive disclosure. 14. Small diffs, characterization tests before refactor. 15. Evals for AI features (groundedness/refusal/cost). 16. Accessibility WCAG-AA + perf budgets at launch. 17. Central notification orchestration (no direct sends). 18. Money-pipe: idempotent billing, entitlement checks. 19. Mobile: staged rollout + crash budgets. 20. FinOps: cost attribution per feature.
21. Trust-safety: classifier cascade, cost-ordered review. 22. Compliance-as-code (SOC2/ISO mappings). 23. AI-Act: phased obligations by risk class. 24. Blindspot hunts before launch. 25. Authenticity: real data in demos, no slop. 26. Documentation with runnable examples. 27. Postmortems blameless, prevention-merged. 28. Monitoring + rollback triggers on deploy. 29. Dependency audit on change. 30. No custom crypto.
31. Context hygiene: compact + progress log past step 10. 32. Parallel work in isolated worktrees. 33. Quarantine > invention for unknowns. 34. Coverage receipts for every behavior change.
