## D. Preserved contradictions (do NOT silently resolve)

1. **Anthropic (+90.2%) vs matched-budget critiques.** Anthropic's headline compares multi-agent against a single agent without a matched token budget; practitioner analyses (E-41) argue budget-matched comparisons shrink the advantage. Both preserved: the 90.2% is vendor-published on an internal eval; the critique is methodological, not a replication.
2. **Anthropic (multi-agent works) vs Cognition (don't build multi-agents).** Resolved *by both parties* as different problem classes — read-heavy parallel research vs write-heavy parallel coding — and by Cognition's 2026 follow-up converging on "writes stay single-threaded." Preserved as a scope distinction, not a disagreement.
3. **Temporal "exactly-once" vs at-least-once reality.** A practitioner blog claims Temporal gives "exactly-once execution semantics"; Temporal's own docs frame the default as at-least-once with dedup+idempotency as the application's job (E-10). Prefer the docs' framing.
4. **Conductor maintenance.** Project FAQ mirrors say active development continues under Orkes; the original Netflix repo is no longer the home. Both true; cite Conductor OSS as canonical.

## E. Negative evidence log (where automation/multi-agent failed or was removed)

- **N-01** AutoGen (Microsoft) → maintenance mode; community moved to AG2 / Microsoft Agent Framework. (Atlas H §H5.)
