# Build Log — <project name>

One file per project, append-only. **Write it before you close the laptop.** If an entry takes more than 5 minutes, you're writing a blog post, not a log.

---

## 2026-__-__

- **Status:** one line — where the build stands tonight.
- **Changed:** what actually changed (commits / files / deploys). Link, don't describe.
- **Decisions:** what you decided + one line of why. (The solo ADR — §14 R-06 shrunk to a bullet. Only irreversible choices get a real ADR: *decision / why / what would reverse it*, `docs/adr/NNNN-title.md`.)
- **Blockers:** what's stuck, and the next concrete step to unstick it.
- **Gates:** any gate run today and its verdict (GO / NO-GO / NOT ASSESSED). Unknowns never pass (§17 §4.1).
